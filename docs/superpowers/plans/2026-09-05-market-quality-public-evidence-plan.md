# 行情质量证据安全投影接入计划

状态：offline-verified，代码与隔离测试已完成，运行启用仍待独立安全审核与部署验收。节点：P1-N12。

## 目标与已授权边界

把采集端已保存的 `REJECTED` 和 `FILTERED` 证据转换成可公开展示的受限摘要，
使数据质量页面能够按日期、来源、证券定位问题。2026-09-05 项目负责人明确允许新增
独立脱敏证据卷：采集端可写，API 服务只读；原始行情卷、数据库和凭据权限保持不变。

先前的日线入库概览已提交为 `8460e2128851a6814cf5c084ed7a270fc41a5f95`。
其部署验证通过后才开始本切片的实现。原有 P6 改动和条件接受记录不属于本切片。

## 已确认的问题

- `MarketDataQualitySink` 的现有证据包含原始对象标识、校验和、自由文本原因和被拒绝记录。
  它不是面向浏览器的安全数据契约，不能原样透传。
- API 服务没有采集端 raw volume 的读取权限。给 API 挂载整个 raw volume，即使只读，
  也会扩大原始数据暴露面，不能作为本方案的替代。
- 当前 PostgreSQL 质量列表只有基金事件；ClickHouse 已接受的 Bar 不能反推出拒绝记录。
- 同一 capture 重放时，现有 sink 对相同证据直接返回。后续接线必须能补齐缺失投影，
  同时保留原始 `recordedAt`，不能把重放时间冒充首次记录时间。

## 最小实现顺序

1. 定义独立的白名单投影契约和纯转换函数，先用脱敏 fixture 验证，不读真实 raw payload。
2. 实现完整快照发布、旧证据回填和重放恢复；回填只读质量文件与 manifest 元数据，
   不读原始 object 内容，不重新采集，不写 Bar。
3. 实现独立的只读证据查询端口及 API。保留基金事件和日线入库概览的现有语义。
4. 页面增加独立的“行情质量证据”区域和安全明细；不提供原始文件下载。
5. 独立审核通过后，才启用已授权的新卷和只读挂载，并验证实际部署边界。

## 必须保持的契约

公开记录仅包含不可逆派生的稳定证据 ID、受支持来源、合法证券代码、周期、请求日期窗口、
状态、固定原因码、受限事件类型、计数及必要时间。原始 capture ID、object ID、checksum、
请求、payload、路径、自由文本原因、原始记录内容及任何凭据不得进入公开契约。
字段必须逐项构造，不能通过复制原始对象再删除几个字段实现脱敏。

快照只有完整发布后才可读取。缺少发布指针、损坏、容量超限、校验失败或不完整状态必须
明确报错，不能变成成功的空列表。只有完整发布且确实零记录的快照，才能显示“未记录到证据”，
且不得据此宣称行情完整或没有质量问题。

保留不可变旧快照，发布指针原子更新；提交指针前失败时保留上一完整快照，不自动清理历史。
替换指针后若目录同步失败，报告提交持久化状态不确定，不能虚称已回滚。
文件名、目录、文件大小、记录数量和读取次数必须有固定上限。拒绝越界路径、符号链接、
非普通文件和文件名与内容不符；用户输入不得直接拼接文件路径。

本切片采用一个有界快照文件：`current.json` 指向 `snapshots/<sha256>.json`。
摘要绑定快照完整 UTF-8 字节，而不是原始行情对象；它提供完整性校验，不是签名认证。
快照最多 10,000 条、8 MiB；单个原始质量文件及 manifest 元数据最多 1 MiB。
达到上限时整次发布失败，不截断或跳过异常文件。后续页和明细固定同一个 `snapshotId`，
避免发布期间翻页产生漏项或重复项。未提供历史时点查询。

公开事件仅保留受支持类型及可校验的证券、时间。原始异常记录中的非法证券或时间投影为
`null`，保留事件本身；API 对公开快照中的非法非空字段仍失败关闭。

`qualityRecordedAt` 与 `captureAvailableAt` 保留原值；快照 `publishedAt` 表达本次公开可见时间。
回填旧证据不得声称其在历史时点已公开。本切片不提供历史 `asOf` 查询。

## 验证与停止条件

- 正常 REJECTED/FILTERED、合法空快照、未知状态和来源、异常时间、自由文本与秘密哨兵不泄漏。
- 幂等重放、语义冲突、写入中断、投影失败恢复、原 recordedAt 保持不变。
- 损坏文件、关联错误、超量、路径穿越、符号链接和不完整快照全部失败关闭。
- API 授权先于读取，非法筛选拒绝，错误不回显内部内容；列表截断或分页不隐藏更多异常。
- UI 分别表达未发布、失败、已发布零记录和筛选零结果，展示发布时间和证据记录时间。
- 既有基金事件、日线概览和采集拒绝行为保持回归通过；没有新增真实下单能力。

权限及文件证据边界按高风险审核。在独立审核条件未满足前，不接入采集运行路径、不挂载新卷，
也不把计划或离线测试称为上线完成。缺失交易日分析、来源价格对账、全市场覆盖与最终墙钟门禁
均不在本切片内。
