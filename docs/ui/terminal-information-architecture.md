`visibleTerminalRoutes` 同时按可用状态、导航标记和角色权限筛选。桌面导航、窄屏导航和首页入口使用同一结果，首页不展示后续版本功能或静态就绪数量。

## 权限矩阵

| 角色             | `terminal:read` | `research:read` | `paper:read` | `operations:read` |
| ---------------- | --------------- | --------------- | ------------ | ----------------- |
| `viewer`         | 是              | 否              | 否           | 否                |
| `researcher`     | 是              | 是              | 否           | 否                |
| `paper_operator` | 是              | 否              | 是           | 否                |
| `platform_admin` | 是              | 是              | 是           | 是                |

- 前端权限用于筛选导航和直达路径提示，服务端授权仍是最终边界。
- 生产角色来自服务端注入的 `window.__KUNLUN_SESSION__.roles`；该值不能替代 API 权限校验。
- `paper:read` 保留为后续模拟组合模块权限，不让它出现在 1.0 导航中。

## 响应式与键盘约定

- `lg` 及以上使用固定侧栏；窄屏复用 Dialog 导航，支持焦点约束、Escape 关闭、焦点返回，选择路径后自动收起。账户与退出入口在窄屏仍可用。
- 页面首个可聚焦入口是“跳到主内容”，主内容容器可被程序化聚焦。
- 桌面和移动导航均有独立可访问名称；当前链接使用 React Router `NavLink` 语义。
- 链接保留可见 focus ring，并尊重减少动画偏好。
- 未知路径进入可返回首页的 404；已知但无权路径显示 forbidden。

基础交互沿用 `components/ui`：纵向字段用 grid/flex 和 `gap-2`，标签与控件间距 8px；原生下拉框、复选框也保留可见键盘焦点。可操作、禁用、请求中的控件分别显示 pointer、not-allowed、progress。提交中锁定本次输入并显示忙碌状态，失败保留输入；后台刷新不卸载正在编辑的规则，失败保留上次结果并提供重试。Dialog 按动态视口限制高度，长内容在弹层内滚动。后续页面仅统一样式，不改变现有路由开放范围。

## 跨模块筛选上下文

`TerminalFilterContextV1` 以 URL query 为单一来源，定义跨模块公共语义：

- `asOf`：必须是带时区的 RFC3339，解析后规范为 UTC ISO 时间；
- `instrument`：可重复参数，必须是 `600519.SH`、`000001.SZ` 或 `430047.BJ` 形式；
- `version`：运行时固定为 `v1`，供后续兼容升级。

Provider 位于 Layout 边界，导航和首页链接保留当前上下文。非法 query 不进入受信筛选值，同时通过 `rejected` 留下明确反馈。筛选上下文本身不触发 API 请求。

## 非目标

- 不因保留旧路径而把后续版本页面作为 1.0 能力展示。
- 不新增 API、数据库表、通知或订单逻辑。
- 不把 NAV/iNAV 描述为成交价。
- 不新增真实交易入口或凭证配置。
