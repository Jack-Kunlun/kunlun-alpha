# P6-N12 耐久门禁一次性验收豁免

日期：2026-08-27

## 决定

项目负责人明确同意一次性豁免 P6-N12 的以下两项验收门禁：

- 使用真实持久化适配器执行故障恢复矩阵；
- 连续 72 小时真实墙钟耐久运行。

本豁免仅用于解除 P6-N13 的前置依赖，不表示上述两项技术证据已经取得，也不把
`TEST_DOUBLE` 或虚拟时钟结果标记为正式通过。

## 已取得证据

- `95686b8`：实现模拟运行恢复、故障矩阵、耐久 runner 与恢复手册。
- `21bade1`：为耐久报告增加证据范围，禁止测试替身取得正式资格。
- Ruff、BasedPyright、6 个定向测试和 `paper-core` 构建通过。
- 虚拟 72 小时报告为 `TEST_DOUBLE + ENGINEERING_EVIDENCE_ONLY`。

## 未豁免边界

- Phase 0 至 Phase 6 继续禁止真实券商连接、真实账户凭据和可调用真实订单路径。
- 模拟订单仍须经过失败关闭的风险检查、幂等执行状态机和账簿对账。
- 不得在产品界面、API 或运行报告中把本豁免表述为真实 72 小时稳定性证明。
- P6-N13 的数据时点、来源、版本、NAV/iNAV 非可成交价格和缺失数据状态仍须完整验收。

## 剩余风险

真实数据库短暂不可用、进程重启和长时间运行下的资源泄漏尚无持续 72 小时直接证据。
当前正在运行的固定名称 r2 进程加载的是修复前源码，不能作为本次数据库隔离修复的证据。
后续接入带 ownership marker 的真实持久化适配器并完成全新的墙钟运行后，应追加正式报告并
关闭本豁免风险；历史记录保留，不覆盖或删除。修复后的新运行必须从零开始满 72 小时，不能
拼接 r2 已运行时长。
